How it works Install

App videos for developers and product teams

Ship a feature.
Show it off the same day.

Most new features never get a video, because making one takes hours. With Showcase Studio, Claude writes it from your repo and you get a polished video in minutes. No CapCut, no clipping by hand.

Install now

Start in your code repo

Showcase Studio works inside your app's own repository. Claude can read your code and docs, and capture screenshots and clips of your app.

The video lives right next to the code, in a showcases folder.

your-app
your-app/
├── src/          ← Claude reads the code
├── README.md     ← and the docs
└── showcases/    ← the video lives here
    └── launch/
        ├── showcase.yaml   the script
        └── assets/         real screens

Be the director

Start a Claude session in your app project and describe what you want to make.

Claude and Showcase Studio take it from there. You get a script, scenes with integrated video and custom graphics, and captions. You can watch the video directly in Claude.

Step in front of the camera

To record yourself speaking the script, use the built-in teleprompter, on your computer or on your phone.

Your recording will be automatically woven into the video, with synced captions. You don't have to line anything up by hand.

Publish it

Export high quality video and upload to destinations like TikTok and YouTube. On a Mac, you can AirDrop the video directly to your phone.

Update it when the app changes

Your showcases are git-managed files. So when your app changes, Claude can update your videos quickly and easily.

your-app
$ git log --oneline -- showcases/launch
a41c9e2 launch: retake the settings screen
7d03b1f launch: add a line about jump gates
3e9f6a0 launch: tighten the hook to 3 seconds
c18b7d4 launch: first cut

Get Showcase Studio

Recommended

Use it in Claude Code

In a terminal:

claude plugin marketplace add kgilpin/showcase-studio
claude plugin install showcase-studio@showcase-studio

Then start Claude Code in a folder for your showcases and run /showcase-studio:showcase new. The app installs itself the first time, and it all runs on the Claude Code subscription you already have.

or

Use the desktop app

Open a folder for your showcases, and work with Claude in the app's terminal. On a Mac, unzip it and move it to Applications.

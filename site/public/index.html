Script to video

The words set the timing

A showcase is a folder: a short script plus your screenshots and recordings. Each scene lasts as long as it takes to say its lines, so there is no timeline to drag. A shorter sentence makes a shorter scene.

Because it is just files, you can commit it, branch it and review it like any other code. 

- id: mirror
  theme: feature
  title: Mirror your iPhone
  captions:
    - text: Your screen, on any TV,
        in ten seconds.
  media:
    kind: image
    asset: shot-mirror

Record your pitch

A teleprompter on your phone

When it is time to talk on camera, open the script on your phone. It scrolls like a teleprompter while you record.

Then tell the studio which part of the recording each scene uses. It cuts the clips, joins the voiceover and times every scene, so your lips and your voice stay together.

Share

Post to TikTok, Instagram and YouTube Shorts

Export a full-quality 9:16 video. The studio writes the caption and hashtags for each platform, checks their limits, copies the text and opens the upload page. On a Mac, it can AirDrop the video to your phone.

You post it yourself. Nothing is linked to your accounts.

Claude Code

Claude is the editor

Type /showcase and the studio opens beside your chat. Ask for changes in plain words. You can also edit in the studio yourself, and Claude sees what you changed.

It runs on the Claude Code subscription you already have, with every tool on your machine. Here, Claude makes a voiceover with the user's own AWS account.

Download

Showcase Studio is a Claude Code plugin. Install the plugin, and it installs the app the first time you use it. Or download the app yourself.

1. Install the plugin

In a terminal:

claude plugin marketplace add kgilpin/showcase-studio
claude plugin install showcase-studio@showcase-studio

Then start Claude Code in a folder for your showcases and run /showcase-studio:showcase new.

2. Or get the app

Version 0.5.0. On a Mac, unzip it and move it to Applications.

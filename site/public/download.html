Download Showcase Studio

Two ways in, same studio. Your first two full-quality video exports are free on each computer; drafts are always free.

Recommended

Use it in Claude Code

In a terminal:

claude plugin marketplace add kgilpin/showcase-studio
claude plugin install showcase-studio@showcase-studio

Then start Claude Code in a folder for your showcases and run /showcase-studio:showcase new. The app installs itself the first time, and it all runs on the Claude Code subscription you already have.

or

Use the desktop app

Open a folder for your showcases, and work with Claude in the app's terminal. On a Mac, unzip it and move it to Applications.
